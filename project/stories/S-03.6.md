# S-03.6 — Cloud spawn and send

do: `cloud_spawn` runs `claude --cloud` and parses the id and URL. `cloud_send` runs `claude -p --cloud <id>`.
done when:
- [ ] The shim scenario passes. An unparsable output returns a readable error that includes the raw output.

## From the spikes (2026-10-04)

- `cloud_spawn`: `claude --cloud "<prompt>"` refuses without a terminal and cannot combine with `-p`, so run it under a pty and parse `session_[A-Za-z0-9]+` and the URL; it exits right after creating the session.
- `cloud_send`: `claude -p "<msg>" --cloud <id> --output-format json` returns `{ok, session_id, url}` (an ack). Never use `SendMessage` to steer a cloud session (SP3).
