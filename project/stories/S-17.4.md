# S-17.4 — One agent per person

do:
1. Adding a person creates their agent: the name they or the owner chose, a look (from the name when none is
   given, the Pixel Zoo `fromName` rule), a main conversation, an Inbox project and a brain workspace
   `~/marcel/brains/<agent-slug>` rendered from `brain/` with that agent's name and persona.
2. The brain keeper keeps one brain per agent (it already loops over agents); each brain gets its own `brain_cwd`.
3. Memory per agent: `memory/<agent-slug>/…` in the same git repo. A migration moves the owner's existing memory
   under `memory/marcel/` with `git mv`, so history is kept. Memory routes and `memory_read/write` are limited to the
   caller's agent.
4. Every session still uses the owner's Claude login (B-38). The worker cap and the usage guard are shared by everyone.
done when:
- [ ] Two people: a message to one brain never reaches the other; memory paths never cross (test).
- [ ] The migration keeps `git log` of the owner's `MEMORY.md`.
