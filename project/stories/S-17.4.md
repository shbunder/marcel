# S-17.4 — Memory per person

do:
1. Each agent's memory lives under `agents/<slug>/` in the one memory repo: `agents/<slug>/MEMORY.md` and
   `agents/<slug>/memory/…` (dated notes and `projects/<slug>.md`). The paths a brain and the app see stay as they
   are (`MEMORY.md`, `memory/…`), so the contract does not change.
2. A one-time move puts the owner's memory under `agents/marcel/` with `git mv`, so history is kept.
3. Every memory reader and writer goes through the caller's agent: the app routes, `memory_read/write`
   (`brain_api.py`), workers' notes (`channel/gateway.py:457-480`), project notes (`projects/store.py:266`).
done when:
- [ ] Two people: neither can read or write the other's memory through any of the four paths (test).
- [ ] After the move, `git log --follow agents/marcel/MEMORY.md` shows the old history.
