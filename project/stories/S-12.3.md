# S-12.3 — Activity tab

do: One card per task, grouped **Needs you** (pinned), Working, Queued, then Done or Failed (last 7 days). Each card shows
title, location, model, age, last activity and PR badge. Swipe to stop a running task, or to archive a
finished one (B-17); an "Archived" filter shows archived tasks. It updates live from WS.
done when:
- [ ] Test: the grouping and ordering view model works.
