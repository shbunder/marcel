# S-02.5 — Contract: projects, artifact versions, boards, avatar sheet

Lead only. Extends S-02.1 for the pixel-classic app decided on 2026-10-12. Wireframes: `scratch/spikes/SP5-avatar/wireframes/` (open `out/marcel-wireframes.html`).

do:
1. **Projects** in `app-api.yaml`: `Project` schema (id, slug, name, goal, repo?, folder?, instructions?,
   claude_project_url?, board_artifact_id, archived, counts {working, needs_you, done_7d}, updated_at);
   `GET/POST /projects`, `GET/PATCH /projects/{id}`, `POST /projects/{id}/archive`,
   `POST /tasks/{id}/move` (body `project_id`). `Task.project_id` (required; every agent has an `inbox`
   project). `POST /conversations/{id}/messages` takes an optional `project_id` (B-32); `Message.project_id`.
   `GET /tasks`, `GET /artifacts` filter by `project_id`.
2. **Artifact versions:** `Artifact.current_version`, `updated_at`, `project_id`, kind `board`;
   `GET /artifacts/{id}/versions`; `GET /artifacts/{id}/content?version=n`. Message kind `artifact` (the
   item-get milestone, first version only).
3. **Events:** `project.created`, `project.updated`, `task.moved`, `artifact.updated` (v2+, with version and
   summary), `brain.rollover` (at, reason, kept). `artifact.created` gains `project_id`.
4. **Boards:** in `dashboard.schema.json` add a `section` widget (title + child widgets) and a `note` widget
   (Marcel's "what this means" lines, with author and time) so a project board is a dashboard.
5. **Avatar sheet:** `avatar-sheet.schema.json` for the sprite sheet JSON (frame size, frame count, loops of
   `[frame, ms]`, required loops `idle thinking working1 working2 working3 needs_you done`).
6. Update the S-12.5 references in descriptions to the new story numbers (Items is S-12.8).
done when:
- [ ] Contract tests: every new operation has examples that validate; every new event validates; a project
  board example validates against `dashboard.schema.json`.
- [ ] The mutation baseline from S-02.1 still holds (every rule can fail).
not in scope: the mock hub's new scenario (S-02.6).
