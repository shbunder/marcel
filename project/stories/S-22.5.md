# S-22.5 — marcel install, without Docker

`deploy/install.sh` needs Docker, `/usr/bin/python3` ≥ 3.12, `deploy/.env.local` and Linux (`check_host`). Port it into
`marcel install` so it runs on a Mac or Linux with only Claude Code (logged in), `git` and `uv`. Read first:
`deploy/install.sh` (every step stays, in the same order), `plan/05-install-anywhere.md` § 3–4.

do:
1. **Ask, then do.** `marcel install` asks for the person's first name and their first buddy's name (default Marcel),
   prints what it will do in plain words (folders, the plugin into `~/.marcel/brain`, the background services, the
   password prompt from S-22.6), and asks "Go ahead? [y/N]". `--yes` skips the question (for `get.sh` re-runs and
   tests). Answers go to `~/.marcel/data/marcel.toml` (`owner_name`; the buddy is made by `marcel-hub setup`).
2. **Checks** in one sentence each: `claude auth status` says logged in (else "Open Terminal, run `claude`, then
   `/login`"); `git` present (macOS: "Run `xcode-select --install`"); `uv` present. No Docker, no `.env.local`
   needed. If `deploy/.env.local` exists (the NUC), it is read as today: hub settings (GitHub token, APNs, ntfy) go to
   `marcel.toml`; `MARCEL_HARRY_TOKEN` goes to `~/.config/marcel/session.env` and `MARCEL_AGENT_NAME` /
   `MARCEL_OWNER_NAME` to the brain render, exactly as `install.sh` does now.
3. **Toolchain without admin:** Python 3.12 via `uv python install 3.12`; the hub's environment with
   `uv sync --frozen` in `~/.marcel/src/hub`; node 22 for this system and CPU (`darwin-arm64`, `darwin-x64`,
   `linux-x64`, `linux-arm64`, checksum checked as today with `shasum -a 256` or `sha256sum`).
4. **The rest as today:** plugin build and `marcel-local` marketplace, version `<v>+<commit>`, hub secret, brain
   render and trust, scratch workspace, then `marcel services install` (S-22.4) and `marcel-hub setup` (owner row,
   first buddy, no QR yet: the QR needs the public address, S-22.8).
5. **Manifest.** Every file and folder the install creates outside `~/.marcel` (LaunchAgents or units, plugin data,
   the marketplace entry, trust entries in `~/.claude.json`, `~/.config/marcel/`) is appended to
   `~/.marcel/install-manifest.json` as it is made. `marcel uninstall` (S-22.10) reads it.
6. **The NUC keeps Docker until S-22.24:** in Docker mode (S-22.4: a `marcel-hub` container and no
   `~/.marcel/state/native`), `install` rebuilds and restarts it as
   today (`deploy/compose.sh up -d --build`) instead of the native hub, and leaves the existing
   `/etc/claude-code/managed-settings.json` alone. `deploy/systemd/` is deleted here (the table generates the units).
7. `deploy/install.sh` becomes a three-line wrapper that runs `marcel install --yes` (the NUC's and `redeploy.sh`'s
   entry point stays). `health.sh` reads service state through `marcel status` instead of `systemctl`, uses a portable file-age check
   instead of GNU `stat -c %Y` (macOS `stat` has no `-c`), and checks the
   hub on `127.0.0.1:7420` as today; its exit codes do not change.
8. `docs/operating.md` § Install: the native steps; Docker steps move to a "Before F22" note until S-22.25; "Family
   members are added from the app (Settings › People)" becomes "Buddies are added from the app (Settings › Buddies)".

The Linux path is first run live on the NUC in S-22.24 (and in Docker mode by every NUC redeploy from here on).
