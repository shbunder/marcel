# S-12.2 — PixelKit: the pixel-classic design system

do:
1. Tokens: the palette (cream `#f6efe4`, ink `#2a1d24`, rose `#d87990`, deep `#9c3e5a`, teal `#3f6b6a`, gold
   `#e2a43a`), a light and a dark variant, spacing on a 2-pt pixel grid, hard 2–3 pt borders, offset "pixel" shadows.
2. Bundle the OFL fonts **Silkscreen** (labels, headings) and **Pixelify Sans** (body). Body text scales with
   Dynamic Type; Silkscreen labels clamp at a maximum size.
3. Components, each with SwiftUI previews and snapshot tests: `DialogBox` (speaker label, ▼ blink),
   `ChoicePrompt` (▶ marker, keyboard and VoiceOver focus), `QuestCard` (state badge, title, project chip,
   progress bar), `ArtifactCard` (gold header, "updated" badge), `ItemGetBanner`, `ProjectChip`, `StateBadge`,
   `PixelTabBar`, `HeartsHeader`.
4. Accessibility: every component has a label that reads as plain words (no "▶", no ALL CAPS spelled out);
   contrast passes WCAG AA in both themes; Reduce Motion stops the ▼ blink.
done when:
- [ ] Snapshot tests for every component in light, dark and the largest Dynamic Type size.
- [ ] An accessibility audit test (`performAccessibilityAudit()`) passes on the component gallery.
