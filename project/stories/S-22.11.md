# S-22.11 — The hub drops the people model

app-api 0.8.0 (S-02.13). ADR-013 § One person, many buddies says what goes and what stays. F17 built the people model
(S-17.1 users and the owner, S-17.2 isolation per person). The brain per agent (S-17.7) and memory per agent (S-17.4)
stay as they are. **`user_id` columns stay** (there is one user row): only the checks that tell two people apart go.
New buddy routes and push routing are S-22.27.

do:
1. **Remove** the `/users…` routes (`users/routes.py`, `users/cli.py`'s member commands), `require_owner`
   (`auth/deps.py:73`), `role_of`, and the per-person checks S-17.2 added in `tasks/routes.py`, `artifacts/`, `ws.py`,
   `adopt.py`, `channel/routes.py` and `selfmod.py` (self-change approval by any paired phone). Tests that build members
   (`test_memory*.py`, `test_people_brains.py`, `test_avatar.py`, `test_cloud.py`) build agents of the one user instead. Device-token checks stay on every route.
   Drop the `RETIRED` entries S-02.13 put in `test_contract_routes.py`.
2. **Migration:** every user is folded into the owner row (`usr_owner`); agents keep their slug, memory folder and
   brain; a `device.agent_id` column is filled with the first live agent of the device's old user, so a family
   member's phone keeps showing their own buddy; `role` goes. `Device` responses carry `agent_id`.
3. **Tests that replace the old ones:** every route with an id in its path answers 401 without a token (looped over
   the app's routes, as `test_isolation.py` did, so a new route must be classified); a phone sees every buddy's
   conversation and tasks.
4. `hub/README.md`: "People" becomes "Buddies".
done when:
- [ ] `make -C hub check` passes; `grep -rn "require_owner\|role_of\|x-owner-only\|UserRole" hub/src` prints nothing.
- [ ] The token loop test fails when the token check is removed from any one router (inert-controls rule).
- [ ] The migration test: a 0.7 database with an owner and one member (two agents, three phones) comes out with one
      user, two agents, three working device tokens, each device's `agent_id` its old owner's agent.
