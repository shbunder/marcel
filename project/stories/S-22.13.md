# S-22.13 — Buddies message each other

carries the message (`SendMessage`, same machine); Marcel only shows it.

   ADR-003). New `runner/src/marcel_runner/role_settings/side.json`, and the existing `worker.json`, get `crossSessionInbound: refuse`
   and `SendMessage`, `ListAgents` in `permissions.deny`, so side threads and quests can neither send nor receive.

   back the same way.

   (brain-api 0.2.0, S-02.16). The hub stores a `buddy` message in both buddies' main conversations ("Marcel → Pip:
   …"); the app shows it from S-22.28.
