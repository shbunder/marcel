# S-22.30 — Notebook drafts and the rollover log belong to one buddy

S-22.29 gave each buddy its own notebook, but the phone still keeps unsaved edits (`DraftStore`,
`notebook.draft.<path>`) and the rollovers it saw (`RolloverLog`) for the phone as a whole. An unsaved edit of Marcel's
`MEMORY.md` comes back on Pip's `MEMORY.md`, and "keep mine" on the conflict screen would overwrite Pip's note with
Marcel's text: data loss. Found by S-22.29's story-verifier.

do:
1. `DraftStore` keys a draft by buddy and path (`notebook.draft.<agent id>:<path>`); `paths`, `draft`, `keep`,
   `discard` and the 50-draft limit are per buddy; `discardAll` (unpairing) forgets every buddy's. Drafts kept under
   the old key move to the buddy shown the first time the store opens with one.
2. `RolloverLog` stores each rollover with the buddy it is about (`brain.rollover`'s `agent_id`) and keeps the last
   ten per buddy; the notebook merges only the buddy shown's. Entries from before move to the buddy shown.
3. `NotebookModel` opens its drafts and rollovers for the buddy shown (`CurrentBuddy`).
done when:
- [ ] `make ios-check` passes; a test shows a draft of Marcel's `MEMORY.md` never appears on Pip's `MEMORY.md` (and goes
      red with the old keying), old drafts move to the buddy shown, and a rollover of Pip's is not in Marcel's list.
