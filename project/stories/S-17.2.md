# S-17.2 — Every request is checked against its person

Today several routes assume one person (see the scoping list in the S-17 scoping notes below). This story closes them.

do:
1. `/tasks` and every `/tasks/{id}/…` route check that the task's agent belongs to the caller; otherwise 404.
2. The app WebSocket sends each task, registry, artifact and approval event only to the devices of the agent's owner
   (`ws.py` sends everything to `usr_owner` today).
3. An artifact without a task goes to its own agent's Inbox, not the hub's first agent. Adoption (`/marcel-adopt`) and
   pushes use the agent's owner.
done when:
- [ ] An isolation test: with two people, user B tries every route on every object id of user A and gets 404, and
      receives none of A's WebSocket events. Removing the check from any one router makes it fail.

`models.py:478-497`, `adopt.py:290-293`, `notify/pusher.py:205-285`.
