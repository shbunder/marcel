# S-22.24 — Move the NUC off Docker

The owner's install must come over with nothing lost: database, memory and its history, artifacts, phones, buddies,
the Cloudflare address (ADR-013 question 7). Opens a PR for the owner (ADR-012: deploy).

It also moves the NUC's home folder from `~/marcel` to **`~/.marcel`**, the home folder on every install (owner,
2026-10-15; ADR-013). Three things make that move delicate:
- **Claude Code keys sessions and workspace trust by folder path.** The brains, workers and scratch folders all get new
  paths, so the running brain sessions cannot simply carry on, and the new folders are not trusted yet.
- **Paths are written down outside the folder:** git worktrees (each worker's `.git` file and the repo's
  `worktrees/` entries), the systemd and tunnel units, `deploy/redeploy.sh`, `deploy/backup.sh` and its timer,
  `deploy/health.sh` and the compose file's `${MARCEL_HOME}` all name `~/marcel` today.
- **`~/.marcel` is not empty on the NUC.** Old Marcel (v2) kept its data there until S-14.3 archives it, and v3's
  adopt script keeps `adopt-token` and `hub-url` in it (`plugins/marcel/scripts/adopt.py`).

do:
1. `marcel migrate` (NUC only; refuses where no `marcel-hub` container exists):
   1. runs `deploy/backup.sh` and stops if it fails;
   2. **checks it can move:** refuses, saying why, when `~/.marcel` holds anything but `adopt-token` and `hub-url`
      (old Marcel's data not archived yet: run S-14.3 first), when a worker session is still running (wait for it or
      stop it from the app), or when `~/marcel` and `~/.marcel` are on different file systems;
   3. stops the hub container (`deploy/compose.sh stop`; it is kept for the move-back) and the runner, never the
      supervisor, and stops the brain sessions after their hand-over (the S-06.8 `PreCompact`-style
      `.marcel/handoff.md`, written by asking each brain to hand over first);
   4. **moves the home folder:** moves `adopt-token` and `hub-url` from `~/.marcel` into `~/marcel`, removes the empty
      `~/.marcel`, then renames `~/marcel` to `~/.marcel` (one `rename`, so there is never a half-moved folder).
      Nothing is left at `~/marcel`: no symlink, no copy, so only one folder is ever live;
   5. **repoints everything that names the old path:** `git worktree repair` in each repository with worker worktrees;
      the systemd units (`deploy/systemd/`, the tunnel unit), `deploy/redeploy.sh`, `deploy/backup.sh` and its timer,
      `deploy/health.sh` and `deploy/install.sh` default to `~/.marcel` (each still reads `MARCEL_HOME`); the user
      units are reinstalled and the system ones print their sudo lines;
   6. copies the container's environment (`deploy/.env.local`) into `~/.marcel/data/marcel.toml` (secrets included,
      file 0600), adding `public_url = "https://marcel-bot.com"` and `self_change_repo = "shbunder/marcel"`, and
      writes `~/.marcel/state/native` so the next steps leave Docker mode (S-22.4);
   7. replaces `/etc/claude-code/managed-settings.json` (ADR-001's file) with `deploy/managed-settings.nuc.json` from
      S-22.6 as a drop-in (the allowlist **and** `env.DISABLE_AUTOUPDATER`: the NUC stays pinned), and writes
      `MARCEL_CLAUDE_PIN=enforce` for the native runner: it prints the
      sudo lines (the old file is kept as `managed-settings.json.before-f22`) and waits for them; the running
      `marcel-claude-daemon` unit keeps its name (S-22.4), so it is adopted, never restarted;
   8. `marcel install --yes` and `marcel connect cloudflare marcel-bot.com` (the tunnel becomes the user's `tunnel`
      service; the old system unit is disabled with the one sudo line it prints);
   9. **trusts the new folders and starts fresh brains:** the runner's prepare step (S-06.2) trusts each brain folder
      under `~/.marcel/brains/` (and `~/.marcel/brain`) and the scratch workspace; each buddy's brain then starts as a
      **rollover with hand-over** (S-06.7): a new session in the new folder that reads the hand-over, so no buddy
      loses the thread. Old transcripts stay under `~/.claude/projects/` by their old path; the hub keeps its own
      copy, so the app's history is unchanged;
   10. `deploy/health.sh` for up to 120 s. Unhealthy: **move back**: stop the native hub, the runner and the user
      tunnel service; rename `~/.marcel` to `~/marcel`, recreate `~/.marcel` holding only `adopt-token` and `hub-url`
      (moved back out), undo the worktree repair (`git worktree repair` again) and the unit changes; delete
      `state/native`; start the container, the old runner unit and the system tunnel again; and say "Moved back to
      Docker; nothing was lost" with the reason. Again only one folder is live.
2. The native hub reads the same data, now at `~/.marcel/data` (paths from S-22.1, default `MARCEL_HOME`); the app-api 0.8 migration (S-22.11) runs on
   first start, after the backup.
3. `docs/operating.md` § Moving off Docker, including the manual way back; every NUC path in `docs/`,
   `deploy/README.md` and `hub/README.md` that still says `~/marcel` says `~/.marcel` (grep).
done when:
- [ ] A dry run on a copy (`MARCEL_HOME` pointing at a restored backup, a throwaway port) passes, then the real run on
      the NUC: the owner's phone keeps working without pairing again; `GET /api/agents` lists the same buddies; the
      memory repo's `git log` is unchanged; the artifact count matches the backup's (log in the PR).
- [ ] A test (`deploy/tests/`) with a fake `health.sh` that fails proves the move-back path starts the container again
      **and** restores the old layout: `~/marcel` holds everything it held, `~/.marcel` holds only `adopt-token` and
      `hub-url`, and the worktrees' `.git` files name `~/marcel` again.
- [ ] Tests: after a good migrate exactly one of `~/marcel` and `~/.marcel` exists (and `~/marcel` does not); migrate
      refuses when `~/.marcel` holds old Marcel's data, and when a worker is running; no unit, script or worktree under
      test still names `~/marcel` (grep in the test).
- [ ] On the NUC after the real run: each buddy answers in the app from a brain whose folder is under `~/.marcel`, its
      first reply picks up the hand-over, and `claude agents --json` lists no session with a `~/marcel` folder.
