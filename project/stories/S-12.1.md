# S-12.1 — Project, MarcelKit, pairing

Three local packages: `MarcelKit` (models, API client, WebSocket, SwiftData cache), `PixelKit` (S-12.2),
`AvatarKit` (S-13.2). Everything is built against the mock hub until wave 3. Wireframes: `scratch/spikes/SP5-avatar/wireframes/` (open `out/marcel-wireframes.html`).

do:
1. Create the Xcode project `Marcel` with the three packages.
2. Generate the API client from `contracts/app-api.yaml` with swift-openapi-generator.
3. Pairing screen: scan the QR → `POST /api/pair` → store the token in the Keychain.
4. WebSocket client (`/api/ws`) with reconnect and `since` replay; a SwiftData cache of messages, tasks,
   projects and artifacts.
done when:
- [ ] `make ios-check` passes.
- [ ] XCTest covers pairing, WS replay after a simulated drop, and that the token is in the Keychain (not UserDefaults).
