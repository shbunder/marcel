# S-02.7 — Contract: people, agent looks, quoted replies and mentions

Lead only. One contract bump (app-api 0.7) for F17–F21, so the hub, the runner and the app can build in parallel.
Wireframes: the explainer https://claude.ai/artifact/KtdD3PMLeyZP7QrwqYLrdv. **Every new field is optional in 0.7** so
the hub's contract-checked tests stay green until each story fills it; every new route goes on
`PENDING_OPERATIONS` in `hub/tests/test_contract_routes.py`.

do:
1. **People.** `User {id, name, role: owner|member, created_at, agent {id, name, look}, device_count,
   quests_this_week}`. `Me.role`. Owner-only routes, marked `x-owner-only: true`: `GET /users`,
   `POST /users {name, agent: {name, look?}}`, `DELETE /users/{id}` (409 `cannot_remove_owner` for the owner),
   `POST /users/{id}/pairing-codes` → `{code, link, expires_at}`. A member gets 403 with a readable message.
   Self-change approvals (`POST /approvals/{id}` on a self-change card) are owner-only too.
2. **Agent looks.** `Agent.look {animal, color, personality}` (enums from `scratch/spikes/SP5-avatar/zoo/zoo.js`)
   and `onboarded_at?`. `look` is the source of truth; `animal` stays as a read-only copy of `look.animal`;
   `palette` and `seed` become optional and deprecated. `AgentUpdate` takes `name`, `look`, `onboarded: true`.
   `GET /agents/{id}/avatar` (the sheet, `avatar-sheet.schema.json`) and `GET /avatar-previews?animal&color&personality&mood`
   (PNG). Event `agent.updated {agent, avatar_etag}` in `events.schema.json`.
3. **Quoted replies.** `Message.reply_to_message_id?`. `channel.schema.json`: `Reply.in_reply_to` is stored; a
   system frame `agent_renamed {name}` tells a brain its new name.
4. **Mentions.** `Mention {kind: task|project|artifact, id, title}`; `NewMessage.mentions[]`, `Message.mentions[]`;
   `GET /mentions?q=&kind=` (≤ 20, the caller's only). The channel `user_message` meta carries `mentions`.
5. **Trackers.** `Project.tracker_url?`. A worker's `report(artifact)` with `kind: link, role: tracker` pins the link
   as the project's tracker (`channel.schema.json`).
6. **Brains per agent.** `runner-api.yaml`: `prepare_brain {agent_slug, name, persona}` renders `brain/` into
   `~/marcel/brains/<slug>`, links its memory and trusts the folder, on the host (the hub runs in Docker).
done when:

- [ ] `make -C hub check` stays green with the new routes pending.
