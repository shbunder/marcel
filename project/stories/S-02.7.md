# S-02.7 — Contract: people, agent looks, quoted replies and mentions

Lead only. One contract bump (app-api 0.7) for F17–F19, so the hub and the app can build in parallel.
Wireframes: `scratch/spikes/SP5-avatar/wireframes/` and the explainer https://claude.ai/artifact/KtdD3PMLeyZP7QrwqYLrdv.

do:
1. **People.** `User {id, name, role: owner|member, created_at}`. `Me` gains `role`. Owner-only:
   `GET /users`, `POST /users {name, agent: {name, look?}}` (creates the person and their agent),
   `DELETE /users/{id}` (revokes their phones, stops their quests, archives their agent),
   `POST /users/{id}/pairing-codes` → `{code, link, expires_at}` (for a member, or the owner's own new phone).
   A member calling an owner route gets 403 with a readable message.
2. **Agent looks.** `Agent` gains `look {animal, color, personality}` and `onboarded_at?`.
   `AgentUpdate` takes `name`, `look`, `onboarded: true`. `GET /agents/{id}/avatar` → the agent's sheet
   (`avatar-sheet.schema.json`, frame 32×32 allowed), `GET /avatar-previews?animal&color&personality&mood` → PNG.
   The lists of animals, colours, personalities and moods are an enum taken from the Pixel Zoo
   (`scratch/spikes/SP5-avatar/zoo/zoo.js`). Event `agent.updated`.
3. **Quoted replies.** `Message.reply_to_message_id?`: the user message this message answers.
   `channel.schema.json` `Reply.in_reply_to` is documented as stored.
4. **Mentions.** `Mention {kind: task|project|artifact, id, title}`. `NewMessage.mentions[]`,
   `Message.mentions[]`; `GET /mentions?q=&kind=` → up to 20 matches for the composer. The channel
   `user_message` meta carries `mentions`.
5. **Trackers.** `Project.tracker_url?` (a claude.ai artifact link, B-46); `ProjectUpdate` accepts it.
6. Mock hub: serve all of the above from examples, with a second person (Emma) and a reply that quotes an older message.
done when:
- [ ] Contract tests round-trip every new example.
- [ ] `walk.sh` covers: owner adds a person → pairing code; member gets 403 on `/users`; a quoted reply; a mention search.
