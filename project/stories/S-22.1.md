# S-22.1 — The hub runs as a plain process

Today the hub only runs in Docker: its settings default to `/data`, `/state` and `/run/marcel` (`hub/src/marcel_hub/app.py`
`Settings`, `DEFAULT_CONFIG_PATH`), it listens on `0.0.0.0`, and `deploy/docker-compose.yml` sets `HOME=/tmp`. ADR-013
runs it natively on macOS and Linux with `uv run marcel-hub` from `~/marcel/src/hub`.

do:
1. `MARCEL_HOME` (default `~/marcel`) is the root of every default: `data_dir` `$MARCEL_HOME/data`, `db_path`
   `data_dir/marcel.db`, the config file `data_dir/marcel.toml`, `redeploy_flag` `$MARCEL_HOME/state/redeploy.flag`,
   `runner_sock` `$MARCEL_HOME/run/runner.sock`, `brain_cwd` `$MARCEL_HOME/brain`, `worker_cwd`
   `$MARCEL_HOME/workspaces/scratch`. `runner_client.py`'s `DEFAULT_SOCKET` (`/run/marcel/runner.sock`) becomes
   `$MARCEL_HOME/run/runner.sock` too. Each can still be set as today (`MARCEL_*` or `marcel.toml`), so the Docker hub
   keeps working until S-22.25. `deploy/docker-compose.yml` gains `MARCEL_HOST: 0.0.0.0` and
   `MARCEL_CONFIG: /data/marcel.toml` (it sets the paths already; `HOME` is `/tmp` in the container, so nothing may
   fall back to `MARCEL_HOME` there). Touching `deploy/` means this lands as a PR (ADR-012).
2. `host` defaults to `127.0.0.1`. Only the tunnel reaches the hub from outside.
3. Nothing in the hub assumes Linux or `/data` (grep for `'/data'`, `'/state'`, `'/run/marcel'` outside the defaults).
4. `hub/README.md`: "Run it without Docker": `cd hub && uv run marcel-hub`, and which defaults come from `MARCEL_HOME`.
done when:
- [ ] Tests in `hub/tests/test_app.py`: with only `MARCEL_HOME=/tmp/x` set, every path setting is under `/tmp/x`; an
      explicit `MARCEL_DATA_DIR` still wins; `host` is `127.0.0.1`.
- [ ] `grep -rn "'/data\|'/state\|'/run/marcel" hub/src` prints only the lines in `Settings`' Docker note, or nothing.
- [ ] `make -C hub check` passes; `docker compose -f deploy/docker-compose.yml config` shows `MARCEL_HOST` and
      `MARCEL_CONFIG` (the NUC keeps working after its next `make -C deploy deploy`).
