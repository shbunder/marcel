# S-18.3 — Chat look

The chat already puts Marcel left and you right; this story changes how it looks (wireframe: explainer, Q1).

do:
1. Marcel's messages: a white bubble (grey in dark mode) with a thin edge, on the left. The avatar sits next to the last
   bubble of a group, 32 pt, with no circle or background, aligned to the bubble's bottom.
2. Your messages: on the right, in your helper's colour (rose for Marcel) with dark text.
3. Special messages get a coloured frame on all four sides and a short label at the top, never a stripe on one side:
   - started: teal, with the project and "Watch ›";
   - needs you: gold with a light tint, with Approve / Not now / Details buttons (replaces `ChoicePrompt`);
   - done: rose, with the item preview (replaces the "YOU GOT" banner);
   - failed: red, with why and what Marcel tries next.
4. A time line between groups more than 15 minutes apart. The pixel font only on labels; body text uses Dynamic Type.
done when:
- [ ] Snapshot tests for each message kind in light and dark, at the default and the largest text size.
- [ ] The owner signs off on how it looks.
