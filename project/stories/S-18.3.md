# S-18.3 — Chat look

The chat reads like the Claude app (ADR-007; wireframes: explainer artifact KtdD3PMLeyZP7QrwqYLrdv, Q1, light and
dark). New components go in `PixelKit/…/Chat/`; the shared `DialogBox` and `ChoicePrompt` stay until S-18.4 and S-18.6
stop using them.

do:
1. **Your messages:** rounded bubbles on the right, in your helper's colour (`Agent.look.color`; rose for Marcel)
   with dark text.
2. **Marcel's replies:** plain formatted text across the full width with the S-18.7 Markdown view; no bubble, no
   avatar per message. Retire `ChatMarkdown`.
3. **Special messages** are the only boxes: a coloured frame on all four sides and a short pixel-font label, never a
   stripe on one side: started (teal, project, "Watch ›"); needs you (gold with a light tint, Approve / Not now /
   Details); done (rose, with the item preview, replacing the "YOU GOT" banner); failed (red, with the milestone's text).
4. **Header and thinking row:** the avatar stays in the header (`AvatarHeader.swift`). A new
   `MarcelChat/ThinkingRow.swift` at the end of the chat plays the avatar with "Marcel is working…" while `agent.state`
   is thinking or working (static under Reduce Motion).
5. **Long-press:** extend the existing "Reply in thread" `.contextMenu` (`FeedRows.swift:51`) to the special cards
   (`CardRows.swift`). The side chat's quoted message (`SideChat/SideChatSheet.swift:80`, a `DialogBox` today) gets the
   new look too.
6. A time line between groups more than 15 minutes apart. Body text uses Dynamic Type; the pixel font only on labels.
done when:

      heading, a list, a table and a code block, each special message, the thinking row.
