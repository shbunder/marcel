# S-17.5 — Sign-in, Face ID and sign out

The pairing screen lives in the app target, which has no test bundle (`project/lessons/ios-screen-packages.md`), so
welcome and onboarding move into a screen package `ios/Marcel/Welcome/`.

do:
1. Welcome: the avatar, "Scan the code from the person who runs Marcel at home", the scanner, a paste-a-link
   fallback, and "No code? Ask the owner to add you."
2. After pairing, when `agent.onboarded_at` is empty: "Hi <name>! Meet your helper": the look picker (S-19.4), the
   name, "Start chatting" (`PATCH /agents/{id}` with `onboarded: true`).
3. Face ID (or the passcode) to open the app, on by default, asked again after 5 minutes in the background.
4. "Sign out of this phone": `DELETE /devices/{self}`, clear the keychain and cache, back to the welcome screen.
done when:
- [ ] UI tests on the mock hub: pair as Emma → onboarding → chat; sign out → welcome.
- [ ] The lock is tested with a fake authenticator and a fake clock (locks after 5 minutes, not after 4).
