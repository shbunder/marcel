# S-18.2 — Mentions

1. `GET /mentions?q=&kind=`: the caller's quests, projects and items whose title matches, newest first, at most 20.
2. `NewMessage.mentions` are checked (they must be the caller's) and stored; a `#project` mention also sets the
   message's `project_id`. `user_frame` (`channel/gateway.py:819`) adds them, and the channel server passes them to

     for something new, and say which quest it went to;
   - pass `in_reply_to` whenever an answer is not for the latest user message (B-41).
