# S-05.9 — Four actions always ask first — send, pay, sign, delete

The owner's rule (2026-10-23, after Anthropic's Claude Duet set the same bar): Marcel **always asks before it sends a
message, makes a payment, signs a document or deletes a file**, even in `auto` mode and even when a tool is
pre-allowed.

Who asks how (today's hub, unchanged):
- **A quest (worker)** gets an approval card on the phone through the channel's permission relay (S-05.1).
- **A buddy's brain or side thread** cannot raise a card (`hub/src/marcel_hub/channel/gateway.py` denies prompts from
  sessions without a task). So for them the hook answers **deny**, with the reason "Start a quest for this; it will ask
  the owner first." The brain then hands the action to a quest, which asks.
- **Sessions with no Marcel hub** (an owner's own laptop session that loaded the plugin, no
  `$CLAUDE_PLUGIN_DATA/hub-secret`): the hook does nothing.

Claude Code first: a plugin `PreToolUse` hook answering `ask`/`deny` is Claude Code's own mechanism. No hub change.

   folder): with the hook answering `ask`, the channel server logs a `notifications/claude/channel/permission_request`
   frame for it. If Claude Code does **not** emit one for a hook-forced ask, stop: switch the worker branch to a
   `PermissionRequest` hook (ADR-010) or write an ADR, and tell the lead.
1. `plugins/marcel/scripts/ask_first.py` — `PreToolUse` hook (matcher `*`, 5 s timeout in `hooks.json`, its own 4 s
   deadline via `signal.alarm` → exit 0 with no output; stdlib only; any error → no decision, logged to stderr). It
   reads `tool_name`, `tool_input` and the session's role (worker vs brain/side, from the same source
   `session_end.py` uses) and decides, from **one table at the top of the file, one commented row per case**:
   - **Allow row first:** Marcel's own tools `mcp__plugin_marcel_*` (reply, report, tasks_send, tasks_stop,
     schedule_delete …) never match.
   - **send**: MCP tool names with a whole-word send/post/reply/publish/comment/email/message verb; `Bash` running
     `gh pr comment`, `gh issue comment`, `mail`, `sendmail`, `osascript` + Messages.
   - **pay**: whole-word pay/payment/purchase/checkout/transfer in the tool name.
   - **sign**: whole-word sign/signature/docusign/esign in the tool name (not design, assign, signal).
   - **delete**: MCP names with delete/remove/trash; `Bash` commands containing `rm`, `rmdir`, `git clean`,
     `git branch -D`, `trash`, `find … -delete`, `shred` as a command word — parsed with `shlex` per `&&`/`;`/`|`
     segment, including after `sudo`, and not inside quoted text (`echo "rm"` is fine).
   - **Housekeeping exception:** a delete whose every target, after resolving `..` and symlinks, lies inside the
     runner's workspaces root (`MARCEL_WORKSPACES`, default `~/marcel/workspaces`, see
     `runner/src/marcel_runner/workspaces.py`) or the session's own worktree (`<repo>-wt/<task-id>`) is allowed.
   Worker → `ask`; brain or side thread → `deny` with the reason above; no hub-secret → nothing.
2. Register it in `plugins/marcel/hooks/hooks.json`; list it in `plugins/marcel/hooks/README.md`.
3. `docs/approvals.md` (new, short): the four actions; quests ask, buddies hand them to a quest; how to add a case.
