# S-17.1 — Users and the owner

1. A `user` table `{id, name, role, created_at}`. A migration creates `usr_owner` with role `owner` and the name from
   `MARCEL_OWNER_NAME`, so existing phones keep working.
2. `marcel-hub setup` (run once on the NUC, safe to run again): creates the owner, the owner's agent "Marcel"
   (giraffe, rose, professional) with its main conversation and Inbox if missing, and prints a QR code for the owner's

   NUC uses (B-38).
