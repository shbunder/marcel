# S-22.10 — One line to install, one command to uninstall

What a colleague types (`plan/05-install-anywhere.md` § The goal).

do:
1. `deploy/get.sh`, run as `curl -fsSL https://raw.githubusercontent.com/shbunder/marcel/main/deploy/get.sh | bash`:
   macOS or Linux only (else one sentence); refuses root; `claude` installed and logged in, else the two lines to do
   it; installs `uv` into `~/.local/bin` with Astral's installer when missing; clones `shbunder/marcel` over https to
   `~/.marcel/src` (or fast-forwards it); runs `marcel install`, then `marcel connect`, which ends with the QR.
   `bash -s join <code>` is reserved for S-22.21. (`shbunder/marcel` is public, so no token is needed.)
2. `marcel uninstall`: offers a backup first (`~/Marcel-backup-<date>.tar.gz` of `~/.marcel/data`), asks once, then
   stops and removes every service, runs `marcel disconnect`, removes every path in `~/.marcel/install-manifest.json`
   (trust entries are removed from `~/.claude.json` key by key, never the whole file), the drop-in (password prompt),
   the `marcel-local` marketplace (`claude plugin marketplace remove`), and finally `~/.marcel`. It never touches Claude
   Code itself, its login, or `uv`.
3. `docs/install.md` for colleagues: what you need (a Mac or Linux computer, Claude Pro or Max, the TestFlight link),
   the one line, the three questions, the password, the Tailscale link, the QR, what "asleep or offline" means, how to
   uninstall. Plain words; no file paths beyond the one line. `README.md` links to it.
done when:
- [ ] On a fresh macOS user account (not an admin is fine if the password step is given an admin's password): the one
      line, answered prompts and the QR pair the phone; the time from paste to paired is recorded.
- [ ] Then `marcel uninstall`: `ls ~/.marcel ~/Library/LaunchAgents/com.marcel.*` finds nothing,
      `launchctl list | grep com.marcel` is empty, `~/.claude.json` has no `marcel` trust entries and is otherwise
      unchanged (a diff against a copy taken before the install), and `claude` still works.
- [ ] Unit tests: uninstall removes exactly the manifest's paths from a fake home and nothing else.
- [ ] `bash deploy/tests/test_redeploy.sh` passes on the Mac (the portability S-22.7 promised).
