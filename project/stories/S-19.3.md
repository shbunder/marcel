# S-19.3 — The app plays each agent's own avatar

Where the avatar shows (ADR-007): the chat header and the thinking row (S-18.3), never beside each reply.

do:
1. AvatarKit loads the agent's sheet from `GET /agents/{id}/avatar`, keeps it in the cache, and falls back to the
   bundled giraffe when offline; it reloads on `agent.updated`. The header (`AvatarHeader.swift`) and the thinking row
   (`ThinkingRow.swift`) play it.
2. **Several helpers in one chat** (a reply's agent differs from the one before it): the reply starts with a speaker
   line, a 16-pt avatar and the helper's name (`SpeakerLine.swift`, placed by `ChatFeed.swift`/`FeedRows.swift`). With
   one helper, no speaker line ever shows.
3. The app icon is not touched: it is the pixel M with the bow tie (`shared/brand/app-icon/`, ADR-008 amendment).
done when:
- [ ] UI test: an `agent.updated` with a new look → the header and the thinking row change.
- [ ] Snapshot: two helpers in one feed → a speaker line only where the speaker changes; one helper → none.
- [ ] Offline start shows the bundled giraffe.
