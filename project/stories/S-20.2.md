# S-20.2 — Project tracker for coding projects

A Jira-like overview of a coding project, readable on the phone and the laptop, built from a claude.ai artifact so
Marcel needs no new screen. The model is this repo's own build board (`project/board.html`, collection `stories`,
statuses Backlog → In Progress → Review → Done).

do:
1. A tracker template in the plugin (`templates/tracker/`), generalised from `project/board.html`: columns by status,
   cards with title, quest, PR link and CI state, a "waiting on you" lane; works at phone width.
2. The kickoff quest (S-20.1) publishes one tracker per coding project and reports it with `report(artifact, kind=link)`;
   the hub pins it to the project as its tracker (`project.tracker_url`).
3. `worker-protocol`: a coding quest in a project with a tracker moves its own card (In Progress when it starts,
   Review with the PR link, Done when the PR is merged) and writes a log row.
4. The project room and the project's tile show "Open tracker".
done when:
- [ ] A fake-claude scripted run: kickoff → tracker link pinned to the project; a quest → its card goes In Progress → Review.
- [ ] Skill lint passes; the template renders at 400 px and 1200 px wide (snapshot).
