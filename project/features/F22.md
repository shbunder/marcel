# F22 — Install anywhere

Anyone with a Claude subscription installs their own Marcel on their own computer (a Mac laptop first, Linux too)
with one line, pairs the app by QR, and removes it with one command. One install is one person with several buddies.
**Proposed** (2026-10-15): nothing starts until the owner accepts [ADR-013](../decisions/ADR-013-install-anywhere.md).
Why and how: [plan/05-install-anywhere.md](../../plan/05-install-anywhere.md).

**Do not `/board sync` F22 until ADR-013 is Accepted**: until then no F22 story or spike is on the board, so none can
be claimed.

## Open decisions

1. **The one password prompt.** Recommended: accept it (Claude Code reads the channel allowlist only from an admin
   file). The alternative avoids it but takes the brain out of Claude's supervisor.
2. **Tailscale account per person.** Recommended: accept it (free, one click). The alternative is a relay the owner runs
   for all traffic.
3. **Any phone can open any buddy.** Recommended: no lock for now. A per-phone "stay on this buddy" lock is one small
   story if a family member should not see the owner's chat.
4. **Self-change on colleagues' installs.** Recommended: off (they update with `marcel update`); turning it on means a
   fork of their own.
5. **Second computers (wave 7).** Recommended: build after waves 5–6 prove out on a colleague's Mac; drop it if nobody
   asks.
