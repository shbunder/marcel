# Contract request — S-04.5 (runner client and event ingest)

Nothing blocks the story. One gap the notifier (S-08.1) will hit.

## 1. A "something broke" push with no task to open

**What.** `PushNotification.deep_link` is required and must be `marcel://task|message|approval/<id>`.
"Marcel cannot reach the NUC" is about the runner, not one task. When no task was live at the time,
there is nothing to link to.

**What the hub does today.** The runner watcher raises the alert through a small interface
(`Alerts.broke(cause, title, body)` / `resolved(cause)`, cause `runner_unreachable`), and a stand-in
logs it. It does not build a `PushNotification`, so nothing is wrong yet.

**Proposed change.** Either make `deep_link` optional for `category: broke`, or add a link for the
system status (e.g. `marcel://status`), so S-08.1 can send this alert without inventing a target.
