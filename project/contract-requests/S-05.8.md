# Contract requests from S-05.8 (session-end hooks)

Against `contracts/channel-protocol.md` (and `task-states.md`). S-05.8 cannot start without these.

1. **A session-end route for plugin hooks.** `POST http://127.0.0.1:7420/channel/session-end` (outside `/api`,
   like the channel, so the tunnel never exposes it). Headers `X-Marcel-Secret` (the hub secret) and
   `X-Marcel-Session` (`CLAUDE_CODE_SESSION_ID`). Body `{event: "stop" | "session_end", reason?}`, where `reason`
   is the `SessionEnd` hook's own (`clear`, `logout`, `prompt_input_exit`, `other`, …). Answer 200
   `{report_owed: boolean}`: true only for a worker whose task is `working` or `needs_you` with no `done` or
   `failed` report since its last prompt. 401 `bad_secret` / `unknown_session` exactly like the channel.
2. **A reason for the transition.** In `task-states.md`, the `working, needs_you, silent → failed` row also
   names "the session ended without a report (plugin `SessionEnd` hook)", with `reason: ended_without_report`.
