# Contract request — S-04.12 (PR status refresh)

S-04.12 worked around this; nothing in `contracts/` was changed.

1. **A plain reason on a PR card when its status is stale** (`app-api.yaml` `Artifact.pr`). The
   story says "no token, a revoked token or GitHub down: the card says so in plain words", but
   `Artifact.pr` is `additionalProperties: false` with only `number`, `state`, `checks` and
   `review`, so the hub has nowhere to send the reason. The hub keeps it on the artifact as
   `meta_json['pr_note']` (e.g. "GitHub refused the hub's token: it was revoked or has expired.
   Make a new read-only token and put it in MARCEL_GITHUB_TOKEN.") and clears it on the next good
   refresh; `to_api` does not send it.
   Proposed: add `pr.note` (string, optional: "Why the status may be out of date, in plain words;
   absent when the last refresh worked") and, optionally, `pr.refreshed_at` (date-time of the last
   good refresh). The hub would then send `artifact.updated` when the note appears or clears.
