# Contract request — S-12.9 (Marcel's notebook)

S-12.9 worked around these; nothing in `contracts/` was changed.

1. **Past rollovers** (`events.schema.json` `BrainRollover`, "shown in Marcel's notebook so a rollover is never
   silent"). The app can only learn of a rollover from the live stream, and the cache does not keep it, so the
   notebook keeps the last ten it saw on the phone. A rollover from before the phone was listening (a new phone, a
   reinstall, an outage longer than the hub's replay buffer) is never shown, which is exactly the silent rollover the
   schema wants to avoid. Proposed: `GET /agents/{agent_id}/rollovers?limit=10` → `[{id, at, reason, kept}]`, newest
   first (the `brain.rollover` event's `data` plus its id and time), 200 with `[]` before the first one.
2. **`If-Match` is URI-encoded by the generated client.** `putMemoryFile` declares `If-Match` as a plain string
   header; swift-openapi-generator writes header values URI-encoded, so the HTTP-standard quoted form (`"<etag>"`)
   arrives as `%22<etag>%22`, which the hub does not strip. The app sends the bare etag, which the description allows.
   Proposed: say in the description that clients should send the bare etag, so other clients do not trip on it.
3. **409 vs 412.** HTTP answers a failed `If-Match` with 412; the contract uses 409 with the current version in the
   body. The app follows the contract. No change asked; noted so nobody "fixes" one side alone.
