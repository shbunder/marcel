# Contract request — S-05.3 (brain tools)

S-05.3 worked around each of these; nothing in `contracts/` was changed.

1. **Pre-allow the brain tools for brain and side sessions** (`runner-api.yaml`, `channel-protocol.md`).
   The runner pre-allows only `mcp__plugin_marcel_marcel__reply` and `…__report`. The brain tools are a
   second plugin server, `tools`, so Claude Code names them `mcp__plugin_marcel_tools__<tool>`
   (`tasks_spawn`, `tasks_list`, … — the list is in `plugins/marcel/tools/README.md`). A brain whose
   tool call raises a permission prompt is denied at once by the hub (no card for a conversation), so
   without the pre-allow the brain cannot start any work. Proposed: on `role: brain` and `role: side`
   spawns, forks and resumes, also pass `--allowedTools mcp__plugin_marcel_tools__*` (or the full list);
   workers do not get them (the hub refuses a worker's call anyway, 403 `not_brain`).
2. **Write the `/brain` API down** (new `contracts/brain-api.yaml`, or a section in `session-api.yaml`).
   It is between two lanes (the plugin's tools server and the hub) and today lives only in code:
   `hub/src/marcel_hub/brain_api.py` and `plugins/marcel/tools/README.md`. Auth: `X-Marcel-Secret` (the
   hub secret) + `X-Marcel-Session` (`CLAUDE_CODE_SESSION_ID`); outside `/api`; 404 on
   `cf-connecting-ip`. Error codes it adds: `bad_secret` (401), `unknown_session` (401), `not_brain`
   (403), `no_secret` (503), `not_set_up` (503: a part built by a later story), `memory_conflict` (409),
   `schedule_not_found`, `schedule_builtin`.
3. **A push category for Marcel's own notices** (`PushNotification.category`). `notify(text, level)`
   maps `urgent` → `broke` and `normal` → `digest`, both linking to the message it posts. That fits
   B-16, but a dedicated `note` category would let the app treat them on their own.
4. **Story wording:** `project/stories/S-05.3.md` lists `artifacts_add`; `plan/02-architecture.md` names
   it `artifacts_publish(…, artifact_id?)`. The tool is `artifacts_publish`; please align the story.
