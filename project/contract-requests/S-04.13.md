# Contract request — S-04.13 (hub catch-up with app-api 0.5)

S-04.13 serves `pr.note`; nothing in `contracts/` was changed.

1. **When a PR card was last refreshed** (`app-api.yaml` `Artifact.pr`). The S-04.12 request
   asked for `pr.note` and, optionally, `pr.refreshed_at`. 0.5.0 added only `note`, so a stale
   card can say *why* it is stale but not *since when*.
   Proposed: add `pr.refreshed_at` (date-time, optional: "When the hub last read this PR from
   GitHub successfully; absent before the first good refresh"). The hub would set it on each good
   refresh (`github.PrRefresher.refresh`) and send it with the next `artifact.updated`; to avoid an
   event every 5 minutes per open PR, it would ride along on events sent for other changes rather
   than send one of its own.
