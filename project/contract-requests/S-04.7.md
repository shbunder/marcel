# Contract request — S-04.7 (artifacts and memory)

Additive only. The hub answers these today; the contract does not list them yet.

1. **`Error.code` list.** Add the codes S-04.7 uses:
   - `invalid_memory_path` (400) — already named in `/memory/files/{path}`, missing from the list;
   - `memory_file_not_found` (404), `memory_unavailable` (503, git could not run; the save is undone);
   - `artifact_not_found` (404).
2. **`putMemoryFile` responses.** Add `404` (`If-Match` names a file that was removed since it was read;
   a 409 cannot carry a `MemoryFile` for a file that is gone) and `503` (`memory_unavailable`).
   `getMemoryTree` and `getMemoryFile` can also answer `503`.
3. **`ETag` header.** The contract says it equals the body's `etag` (bare hex). HTTP quotes ETags. The
   hub sends the bare value as written and accepts `If-Match` bare, quoted or `W/`-prefixed. Say so,
   so the app does not depend on either form.
4. **PR status source** (not a contract change, a decision): S-04.7 says "`gh api` on the runner, or a
   GitHub token on the hub (decided in F02)". No ADR records it. The hub has a `PrStatusSource` port
   and a `gh api` → `pr` mapper, but no source is wired until this is decided.
